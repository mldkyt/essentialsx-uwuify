# essentialsx-uwuify

## What the fuck?

This tool makes a beautified version of the messages.properties file found in EssentialsX.

## How to use?

1. Clone repository
2. Download a copy of EssentialsX Minecraft plugin
3. Extract "messages.properties" from the JAR file (the jar file is pretty much a ZIP file)
4. `python -m venv .venv`
5. `.venv/bin/pip install -r requirements.txt`
6. `.venv/bin/python maker.py`
7. Rename "messages-uwu.properties" to "messages.properties"
8. Overwrite the one in archive
9. Done!
